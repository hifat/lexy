## เครื่องที่กูแนะนำให้ลุย — **Active** (บน HackTheBox)

### ทำไมต้อง “Active”?

* เป็น **real-world style Windows AD environment** ที่จำลอง Domain Controller จริง ๆ
* มี **ช่องโหว่แบบครบสูตร** ตั้งแต่ SMB, LDAP, Kerberos, Lateral Movement
* เครื่องนี้ถ้าลงลึกได้ จะสอนมึงเรื่องความซับซ้อนขององค์กรใหญ่ ๆ จริง ๆ
* พวกมือโปร OSCP ชอบฝึกกับเครื่องนี้ก่อนลุยสนามจริง
* เจ็บแบบสมจริงแต่ไม่เจ็บจนเลิกเล่น!

---

## แผนลุย Active เครื่องนี้

1. **Recon:**

   * `nmap -sC -sV -p- <IP>`
   * `enum4linux -a <IP>`
   * เช็ค SMB shares และ users

2. **Enumeration:**

   * ใช้ BloodHound หา privilege escalation path
   * รัน `rpcclient` และ `smbclient` ส่องช่องโหว่

3. **Exploitation:**

   * ใช้ credential ที่ได้ลองผ่าน `impacket` tools
   * ลอง Pass-the-Hash หรือ Pass-the-Ticket

4. **Privilege Escalation และ Lateral Movement:**

   * หาเครื่องอื่นใน domain
   * ขยายสิทธิ์โดยใช้เครื่องมือและสคริปต์ต่าง ๆ
