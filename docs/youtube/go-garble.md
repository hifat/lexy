### ภาพรวมเนื้อหา

คลิปวิดีโอนี้เปรียบเสมือนสนามประลองระหว่าง "ผู้สร้างมัลแวร์" และ "นักวิเคราะห์ความปลอดภัย" ในโลกของภาษาโปรแกรม Go (หรือ Golang) โดยจะแสดงให้เห็นว่าทำไมผู้พัฒนาโปรแกรมไม่พึงประสงค์ (มัลแวร์) ถึงนิยมใช้ภาษา Go มากขึ้น และในขณะเดียวกัน นักวิเคราะห์มีเครื่องมือและเทคนิคอะไรบ้างในการแกะรอยโปรแกรมเหล่านี้ ตั้งแต่การวิเคราะห์โปรแกรมแบบปกติ ไปจนถึงการรับมือกับโปรแกรมที่ถูก "อำพรางโค้ด" (Obfuscation) เพื่อให้ยากต่อการตรวจสอบ

### เนื้อหาในคลิปโดยละเอียด

1. **ทำไมภาษา Go ถึงเป็นที่นิยมในการสร้างมัลแวร์?** \[[00:00](http://www.youtube.com/watch?v=gewnAzaZXQo&t=0)\]

   -  วิดีโอเริ่มต้นด้วยการอธิบายข้อดีของภาษา Go เช่น การที่สามารถคอมไพล์ (compile) ครั้งเดียวแล้วนำไปรันได้หลายระบบปฏิบัติการ (cross-platform), ได้ไฟล์โปรแกรมที่พกพาสะดวก, โค้ดอ่านง่าย, มีระบบจัดการหน่วยความจำที่ปลอดภัย และยังสามารถทำงานในระดับลึก (low-level) ได้ ทำให้เหมาะกับการพัฒนาแอปพลิเคชันขนาดใหญ่ และในทางกลับกันก็เป็นที่นิยมในการสร้างมัลแวร์ด้วย

2. **การวิเคราะห์โปรแกรม Go ทั่วไป (ที่ยังไม่ถูกอำพรางโค้ด)**

   -  ผู้จัดทำคลิปได้สร้างโปรเจกต์ "มัลแวร์" ปลอมๆ ขึ้นมาด้วยภาษา Go โดยมีฟังก์ชันง่ายๆ คือการพิมพ์ข้อความ "Hello world" และ "please subscribe" ซึ่งเป็น "รหัสลับ" ที่ซ่อนอยู่ \[[02:56](http://www.youtube.com/watch?v=gewnAzaZXQo&t=176)\]
   -  จากนั้น เขาได้คอมไพล์โปรแกรมออกมา 2 แบบ คือ `debug.exe` (มีข้อมูลสำหรับดีบักครบถ้วน) และ `release.exe` (พยายามลบข้อมูลที่ไม่จำเป็นออกไป) \[[03:59](http://www.youtube.com/watch?v=gewnAzaZXQo&t=239)\]
   -  เมื่อนำไฟล์ทั้งสองไปวิเคราะห์ด้วยเครื่องมือมาตรฐานอย่าง **Binary Ninja, IDA, และ Ghidra** ก็พบว่าถึงแม้จะเป็นเวอร์ชัน `release.exe` ที่พยายามลบข้อมูลแล้ว แต่ก็ยังสามารถค้นหาข้อความที่เป็น "รหัสลับ" (`please subscribe`) เจอได้ไม่ยาก และยังพอจะเห็นโครงสร้างของฟังก์ชันต่างๆ ได้อยู่ [00:07:30 - 00:10:09]
   -  จากนั้นได้ลองใช้เครื่องมือที่สร้างมาเพื่อวิเคราะห์ภาษา Go โดยเฉพาะอย่าง **Redress** \[[10:53](http://www.youtube.com/watch?v=gewnAzaZXQo&t=653)\] และ **Go ReSim** \[[14:14](http://www.youtube.com/watch?v=gewnAzaZXQo&t=854)\] ซึ่งเครื่องมือเหล่านี้ช่วยดึงข้อมูลเชิงลึก เช่น เวอร์ชันของ Go ที่ใช้สร้างโปรแกรม, สถาปัตยกรรม, และข้อมูลโมดูลต่างๆ ได้ดีขึ้น แต่ก็ยังไม่สมบูรณ์แบบนักสำหรับไฟล์ที่ถูกลบข้อมูลไปแล้ว

3. **การอำพรางโค้ด (Obfuscation) ด้วย Garble**

   -  จุดสำคัญของคลิปคือการแนะนำเครื่องมือชื่อ **Garble** \[[16:47](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1007)\] ซึ่งเป็นเครื่องมือที่ผู้สร้างมัลแวร์ใช้เพื่อ "ป่วน" หรือ "อำพราง" โค้ดของโปรแกรมที่เขียนด้วย Go ทำให้การวิเคราะห์ทำได้ยากขึ้นอย่างมหาศาล
   -  เมื่อนำโปรเจกต์มัลแวร์เดิมมาคอมไพล์ด้วย Garble จะได้ไฟล์ใหม่ชื่อ `garbled.exe` \[[19:31](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1171)\]
   -  ผลลัพธ์คือ **เครื่องมือวิเคราะห์ทั้งหมดที่เคยใช้ได้ผลก่อนหน้านี้ กลับแทบจะใช้งานไม่ได้เลย** การค้นหาข้อความ "รหัสลับ" ไม่เจออีกต่อไป, ชื่อฟังก์ชันกลายเป็นตัวอักษรที่อ่านไม่รู้เรื่อง และโครงสร้างโปรแกรมก็ดูยุ่งเหยิงไปหมด [00:20:04 - 00:22:54]

4. **การแกะรอยโปรแกรมที่ถูกอำพรางด้วย Garble**

   -  เมื่อฝ่ายแดง (ผู้สร้างมัลแวร์) มีเครื่องมืออำพราง ฝ่ายน้ำเงิน (นักวิเคราะห์) ก็มีเครื่องมือแกะรอยเช่นกัน วิดีโอได้แนะนำเครื่องมือสำคัญคือ **Go String Ungarbler** จากทีมงานของ Google Cloud และ Mandiant \[[24:51](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1491)\]
   -  เครื่องมือนี้ถูกออกแบบมาเพื่อ **ถอดรหัสข้อความ (strings) ที่ถูกอำพรางโดย Garble โดยเฉพาะ**
   -  ผลลัพธ์คือ Go String Ungarbler สามารถดึง "รหัสลับ" (`please subscribe`) ที่ซ่อนอยู่ออกมาจากไฟล์ `garbled.exe` ได้สำเร็จ ทั้งๆ ที่เครื่องมืออื่นก่อนหน้านี้ทำไม่สำเร็จ \[[28:15](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1695)\]

5. **เครื่องมืออื่นๆ และแหล่งข้อมูลเพิ่มเติม**
   -  วิดีโอได้แนะนำเครื่องมืออื่นๆ ที่น่าสนใจเพิ่มเติม เช่น **Ungarble** (ปลั๊กอินสำหรับโปรแกรม Binary Ninja เพื่อแกะรอยโปรแกรมที่ถูก Garble) \[[31:01](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1861)\] และ **Go Resolver** (เครื่องมือแกะรอยอัตโนมัติสำหรับ IDA Pro และ Ghidra) \[[32:31](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1951)\]

### การสาธิต (Demo) ที่แสดงในคลิป

ในคลิปมีการสาธิตการใช้งานเครื่องมือต่างๆ ให้ดูเป็นขั้นตอนอย่างชัดเจน ดังนี้ครับ

**Demo 1: การสร้างและวิเคราะห์โปรแกรม Go แบบปกติ**

1. **สร้างโปรเจกต์:** สร้างโปรแกรม Go ง่ายๆ ที่มี 2 ส่วน คือ `main.go` และ `secret.go` โดยให้ส่วน `secret` มีฟังก์ชันที่พิมพ์ข้อความ "please subscribe" \[[02:34](http://www.youtube.com/watch?v=gewnAzaZXQo&t=154)\]
2. **คอมไพล์:** คอมไพล์โปรแกรมออกมา 2 ไฟล์ คือ `debug.exe` และ `release.exe` (เวอร์ชันพยายามลบข้อมูล) \[[03:59](http://www.youtube.com/watch?v=gewnAzaZXQo&t=239)\]
3. **วิเคราะห์ด้วยเครื่องมือทั่วไป:** เปิดไฟล์ `debug.exe` และ `release.exe` ด้วยโปรแกรม **Binary Ninja** \[[07:30](http://www.youtube.com/watch?v=gewnAzaZXQo&t=450)\], **IDA** \[[08:46](http://www.youtube.com/watch?v=gewnAzaZXQo&t=526)\], และ **Ghidra** \[[09:39](http://www.youtube.com/watch?v=gewnAzaZXQo&t=579)\] เพื่อแสดงให้เห็นว่า แม้จะเป็นเวอร์ชัน `release` ก็ยังสามารถค้นหาข้อความ "please subscribe" เจอได้ในส่วนของ strings
4. **วิเคราะห์ด้วยเครื่องมือเฉพาะทาง:** รันโปรแกรม **Redress** \[[12:16](http://www.youtube.com/watch?v=gewnAzaZXQo&t=736)\] และ **Go ReSim** \[[14:52](http://www.youtube.com/watch?v=gewnAzaZXQo&t=892)\] กับไฟล์ `release.exe` เพื่อแสดงการดึงข้อมูลจำเพาะของภาษา Go เช่น Build ID และ Go version

**Demo 2: การอำพรางโค้ดด้วย Garble และผลกระทบ**

1. **ติดตั้ง Garble:** แสดงคำสั่งติดตั้ง Garble ผ่าน command line \[[18:22](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1102)\]
2. **คอมไพล์ด้วย Garble:** ใช้คำสั่ง `garble build` กับโปรเจกต์เดิมเพื่อสร้างไฟล์ `garbled.exe` \[[18:55](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1135)\]
3. **เปรียบเทียบผล:** ใช้คำสั่ง `strings` ง่ายๆ กับไฟล์ `release.exe` และ `garbled.exe` เพื่อแสดงให้เห็นว่าไฟล์ที่ผ่าน Garble มาแล้ว จะไม่แสดงข้อความ "please subscribe" อีกต่อไป \[[20:04](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1204)\]
4. **ทดสอบกับเครื่องมือวิเคราะห์:** เปิดไฟล์ `garbled.exe` ด้วย **Binary Ninja** \[[20:24](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1224)\], **IDA** \[[20:46](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1246)\], และ **Ghidra** \[[21:17](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1277)\] อีกครั้ง เพื่อแสดงให้เห็นว่าเครื่องมือเหล่านี้ไม่สามารถแสดงชื่อฟังก์ชันและโครงสร้างโปรแกรมที่อ่านเข้าใจได้เหมือนเดิม
5. **ทดสอบกับเครื่องมือเฉพาะทาง:** รัน **Redress** \[[22:02](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1322)\] และ **Go ReSim** \[[22:54](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1374)\] กับไฟล์ `garbled.exe` ซึ่งผลลัพธ์แสดงให้เห็นว่าเครื่องมือเหล่านี้ก็ไม่สามารถดึงข้อมูลที่เป็นประโยชน์ออกมาได้เช่นกัน

**Demo 3: การถอดรหัสข้อความที่ถูกอำพราง**

1. **เตรียมเครื่องมือ:** แสดงการดาวน์โหลด (clone) และติดตั้งเครื่องมือ **Go String Ungarbler** จาก GitHub \[[27:13](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1633)\]
2. **รันคำสั่งถอดรหัส:** ใช้คำสั่ง `go_string_ungarbler.py` กับไฟล์ `garbled.exe` เพื่อสั่งให้โปรแกรมถอดรหัสข้อความและบันทึกลงในไฟล์ใหม่ \[[27:46](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1666)\]
3. **แสดงผลลัพธ์:** เปิดไฟล์ผลลัพธ์ (`strings_dump.txt`) ขึ้นมาโชว์ ซึ่งจะเห็นข้อความ "please subscribe" ถูกถอดรหัสออกมาได้สำเร็จอย่างชัดเจน \[[28:15](http://www.youtube.com/watch?v=gewnAzaZXQo&t=1695)\]

โดยสรุป คลิปนี้ให้ความรู้ที่ครอบคลุมและทันสมัยเกี่ยวกับการต่อสู้ทางไซเบอร์ในมิติของภาษา Go พร้อมทั้งมีการสาธิตการใช้งานเครื่องมือต่างๆ ให้เห็นภาพจริง ซึ่งเป็นประโยชน์อย่างมากสำหรับผู้ที่สนใจด้านการวิเคราะห์มัลแวร์และวิศวกรรมย้อนกลับ (reverse engineering) ครับ
