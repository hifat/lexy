# Screen UI

![YT](https://youtu.be/_FUw-88-eHc)

วิดีโอนี้เป็นบทเรียนเบื้องต้นเกี่ยวกับ **Screen GUI** ใน *Roblox* โดยผู้สอน (Ethan) อธิบายถึงวิธีการสร้างและคุณสมบัติ (Properties) สำคัญต่างๆ ที่ใช้ในการปรับแต่งหน้าจอเมนูหรือส่วนติดต่อผู้ใช้งานภายในเกม:

* **การสร้าง Screen GUI (0:04):** เริ่มต้นจากการเพิ่ม *Screen GUI* เข้าไปใน *Starter GUI* ซึ่งเป็นที่ที่เก็บข้อมูล UI ที่จะแสดงบนหน้าจอของผู้เล่น
* **คุณสมบัติที่สำคัญ (0:22):**
    * **Archivable (0:43):** กำหนดว่า UI นี้สามารถคัดลอก (Clone) หรือบันทึกได้หรือไม่ หากปิดไว้ UI จะไม่แสดงผลและไม่ถูกคัดลอกไปยัง *Player GUI*
    * **Display Order (2:23):** ควบคุมลำดับชั้นการแสดงผลของ UI หลายตัว ยิ่งค่ามาก ยิ่งอยู่ด้านบน
    * **Enabled (3:32):** สวิตช์เปิด-ปิดการแสดงผลของ UI
    * **Ignore GUI Inset (3:48):** หากเปิดใช้งาน UI จะแสดงผลเต็มหน้าจอโดยไม่ถูกแถบบาร์ด้านบน (Top bar) ของ *Roblox* บดบัง เหมาะสำหรับการทำเมนูหลัก
    * **Reset on Spawn (5:10):** กำหนดว่าเมื่อตัวละครตายและเกิดใหม่ UI จะหายไปหรือรีเซ็ตกลับไปเป็นค่าเริ่มต้นหรือไม่

วิดีโอนี้สรุปจบด้วยการแนะนำว่าในตอนถัดไป จะมีการพูดถึงเรื่องของ **Frames** และการปรับแต่งสี (Color properties) ต่อไป (6:40)
