# K6

```bash
docker pull loadimpact/k6
```

```bash
 k6:
    image: loadimpact/k6
    container_name: k6
    environment:
      - K6_OUT=influxdb=http://influxdb:8086/k6
    volumes:
      - ./scripts:/scripts
```
K6_OUT คือ จะให้ข้อมูลที่ test เสร็จไป OUT ออกที่ให้ในท่นี้เลือก http://influxdb:8086/k6 (`http://<service_name_docker_compose>:<port>/<db_name>`)

/scripts/test.js
```js
import http from 'k6/http'

export default function() {
   http.get("http://host.docker.internal:3500/ht")
}
```

```bash
docker compose  run --rm k6 run /scripts/test.js
```

## Flags
- `-u, --vus <int>` จำนวน users
- `-d, --duration <duration>` ใช้เวลายิงกี่วิ
- `-i, --interations <int>` ให้ยิงกี่ request ในช่วง \<duration>


```bash
docker compose  run --rm k6 run /scripts/test.js -u5 -d5s   #d5s d5m d5h d1m5s
```
