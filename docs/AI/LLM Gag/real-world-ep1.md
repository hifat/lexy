## 💥 Real-World Style Machine แนะนำสำหรับเริ่มต้น (ใน HackTheBox)

### 1. **Active**

* ระบบ Windows ที่เน้นเจาะช่องโหว่ใน Active Directory
* ต้องใช้เทคนิคหลากหลาย ตั้งแต่แสกน, โจมตีช่องโหว่ SMB, Lateral Movement, และ Privilege Escalation
* เรียนรู้การใช้เครื่องมืออย่าง `impacket`, `BloodHound`, และ `PowerShell`

### 2. **Forest**

* เครื่อง Windows ที่จำลอง AD Environment ใหญ่กว่า Active
* เหมาะกับคนที่อยากเจาะ Domain Controller และเข้าใจระบบ Domain จริง ๆ
* ต้องใช้ความรู้ Kerberos, NTLM relay, และโจมตีช่องโหว่ใน AD

### 3. **Vault**

* Linux server ที่เน้นโจมตีบริการจริงในระบบ
* มีการตั้งค่าที่สมจริง มีหลายบริการ เช่น SSH, HTTP, Database
* เหมาะกับคนที่อยากฝึกเจาะ Linux real-world server

---

## 🧰 สิ่งที่ควรเตรียมตัวก่อนลุย

* **ความรู้พื้นฐาน** Windows/Linux commands
* **เครื่องมือ**: Kali Linux, Impacket tools, CrackMapExec, BloodHound
* **ทักษะ**: Recon, Enumeration, Exploitation, Privilege Escalation
* **ใจ**: ต้องพร้อมเจอความซับซ้อนและอาจเจอ dead-end บ้าง

---

## 🔥 เริ่มยังไงดี?

1. เลือกเครื่องใน HTB ที่เป็น real-world (แนะนำ Active หรือ Vault)
2. ลงทะเบียน VPN และเชื่อมต่อให้เรียบร้อย
3. เริ่มสแกนระบบ และทำ Recon โดยละเอียด

   * ใช้ `nmap`, `enum4linux`, `rpcclient`, `smbclient` ฯลฯ
4. ค่อย ๆ วิเคราะห์และหาจุดอ่อน
5. ถ้าติดขัด บอกกู! จะช่วยแนะนำเทคนิคเฉพาะ
