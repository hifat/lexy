## 1. Language Model ทำงานอย่างไร (5 นาที)

Language Model คือโมเดลที่เรียนรู้รูปแบบภาษา แล้วใช้ความรู้นั้นคาดการณ์ว่าข้อความถัดไปน่าจะเป็นอะไร

ตัวอย่าง:

ข้อความที่ได้รับ:

`I love`

โมเดลอาจคาดการณ์คำถัดไปได้ว่า:

| คำถัดไป | ความน่าจะเป็นตัวอย่าง |
| ------- | --------------------- |
| you     | 60%                   |
| Python  | 25%                   |
| coding  | 15%                   |

ตัวเลขนี้เป็นเพียงตัวอย่างเพื่ออธิบายแนวคิด ไม่ใช่ผลจากโมเดลที่ฝึกจริง

แนวคิดนี้เรียกว่า Next-token Prediction

แล้ว Token คืออะไร?

Token คือหน่วยย่อยของข้อความที่โมเดลนำไปประมวลผล เช่น

- `Hello` อาจเป็น 1 Token
- `I love Python` อาจแบ่งเป็น 3 Tokens
- `banana` อาจแบ่งเป็นตัวอักษร `b`, `a`, `n`, `a`, `n`, `a`

วิธีแบ่ง Token มีหลายแบบ วันนี้เราจะเริ่มจากการแบ่งทีละตัวอักษร เรียกว่า Character-level Tokenization

## 2. คณิตศาสตร์ที่ใช้กับ Language Model (5 นาที)

วันนี้เราจะใช้แนวคิดเรื่อง Probability (ความน่าจะเป็น)

สมมติว่าเราเห็นตัวอักษร `a` แล้วพบว่าตัวอักษรถัดไปเป็น:

- `b` จำนวน 8 ครั้ง
- `c` จำนวน 2 ครั้ง

รวมทั้งหมด 10 ครั้ง

เราคำนวณได้ดังนี้:

โอกาสที่ตัวถัดไปเป็น b

\\[ P(b) = \frac{8}{10} = 0.8 = 80\\% \\]

โอกาสที่ตัวถัดไปเป็น c

\\[ P(c) = \frac{2}{10} = 0.2 = 20\\% \\]

คำอธิบายสัญลักษณ์:

- `P` หมายถึง Probability หรือความน่าจะเป็น
- `b` หมายถึงตัวอักษรที่เราต้องการทำนาย
- `8` หมายถึงจำนวนครั้งที่พบ b
- `10` หมายถึงจำนวนครั้งทั้งหมด

หลักการคือ:

ความน่าจะเป็น = จำนวนครั้งที่พบ ÷ จำนวนครั้งทั้งหมด

ทำไมต้องเรียนเรื่องนี้?

เพราะ Language Model ต้องประเมินว่า Token แต่ละตัวมีโอกาสเป็นข้อความถัดไปมากน้อยแค่ไหน

ในอนาคตเราจะใช้แนวคิดนี้ร่วมกับ Neural Network เพื่อเรียนรู้รูปแบบที่ซับซ้อนขึ้น

## 1\. ทำความเข้าใจ Language Model (5 นาที)

สมมติว่าเราให้ข้อความนี้กับโมเดล\:

`I love`

โมเดลต้องประเมินว่าข้อความถัดไปอาจเป็นอะไร เช่น

| Token ถัดไป | โอกาสตัวอย่าง |
|--------|--------|
| you | 60% |
| Python | 25% |
| coding | 15% |

นี่คือแนวคิด **Next-token Prediction** หรือการทำนาย Token ถัดไป

Token คือหน่วยข้อความที่โมเดลใช้ประมวลผล อาจเป็นคำ ส่วนของคำ หรือแม้แต่ตัวอักษร ขึ้นอยู่กับวิธี Tokenization

วันนี้เราจะใช้วิธีที่ง่ายที่สุดก่อน คือแบ่งข้อความทีละตัวอักษร

ตัวอย่าง\:

`banana` → `b`, `a`, `n`, `a`, `n`, `a`

## 2\. คณิตศาสตร์ที่จำเป็น (5 นาที)

เราจะใช้ความน่าจะเป็น (Probability)

สมมติว่าเมื่อเห็นตัวอักษร `a` เราพบตัวอักษรถัดไปดังนี้\:

- `b` จำนวน 8 ครั้ง
- `c` จำนวน 2 ครั้ง

รวม 10 ครั้ง

วิธีคำนวณ\:

**โอกาสของ b** \= จำนวนครั้งที่พบ b ÷ จำนวนครั้งทั้งหมด

\= 8 ÷ 10 = 0.8 = 80%

**โอกาสของ c** \= 2 ÷ 10 = 0.2 = 20%

ถ้าเขียนเป็นสูตรคณิตศาสตร์จะได้\:

\[
P(b \mid a) = \frac{8}{10} = 0.8
\]

ความหมายของแต่ละส่วน\:

- `P` คือความน่าจะเป็น
- `b` คือ Token ที่ต้องการทำนาย
- `a` คือ Token ที่เรารู้อยู่แล้ว
- `8` คือจำนวนครั้งที่พบ b หลัง a
- `10` คือจำนวนครั้งทั้งหมดที่พบตัวอักษรถัดจาก a

**ทำไมต้องใช้คณิตศาสตร์นี้?**

เพราะโมเดลต้องเปรียบเทียบว่า Token แต่ละตัวมีโอกาสเป็นคำตอบถัดไปมากแค่ไหน

ในโค้ด เราจะใช้ `count / total` เพื่อคำนวณค่านี้

## 3\. ลงมือเขียน Python (12 นาที)

วันนี้เราจะสร้าง **Bigram Language Model**

Bigram คือโมเดลที่เรียนรู้ความสัมพันธ์ระหว่าง Token ที่อยู่ติดกันสองตัว

ตัวอย่างข้อความ\:

`ababac`

เราสามารถจับคู่ตัวอักษรที่อยู่ติดกันได้ดังนี้\:

**คู่ตัวอักษรที่ได้จากข้อมูล**

คู่ที่ 1 **a → b**

คู่ที่ 2 **b → a**

คู่ที่ 3 **a → b**

คู่ที่ 4 **b → a**

คู่ที่ 5 **a → c**

---

**เมื่อเห็น a จะพบว่า**

b ตามมา 2 ครั้ง (66.7%)

c ตามมา 1 ครั้ง (33.3%)
