### Zoom Controls
- Track zoom: `opt + scroll`
- Fit zoom: `z`
- Horizon zoom: `cmd + [L | R]`


### Tracks, Regions
- Track zoom: `opt + scroll`
- Duplicate regions: `opt + drag` (Also use this with track)
- Duplicate only track: `cmd + d`
- Join region: `j`

### Key
- Transpose: `opt + [Up | Dwn]`
