## GPS
- Earth Resource Observation System(EROS) = ระบบสังเกตการณ์ทรัพยากรโลก เช่น ดาวเทียม GPS ISS
- EROS Data Informatic Platfrom Service(EDIPS) = บริการข้อมูลและแพลตฟอร์มข้อมูล EROS (Public API)
- Fire Information for Resource Management System(FIRMS) = เผยแพร่ข้อมูลจุดความ
ร้อนทั่วโลก อัพเดทภายใน 3 ชั่วโมง สังเกตจากเซ็นเซอร์ the Moderate Resolution Imaging Spectroradiometer (MODIS)
บนดาวเทียม Aqua และ Terra และชุดเครื่องวัดรังสีอินฟราเรดที่มองเห็นได้ (VIIRS) ที่อยู่บนดาวเทียม S-NPP และ NOAA 20
Google Point Marker(GPX) = เป็น Schema ของ XML ที่ออกแบบมาเป็นรูปแบบข้อมูล GPS 
- Keyhole Markup Language(KML) = ส่วนหนึ่งของเอกสาร XML สำหรับการทำโมเดลและจัดเก็บคุณลักษณะทางภูมิศาสตร์ 
เช่น จุด เส้น ภาพ รูปทรง สำหรับแสดงบน google earth google map
- Keyhole Markup Zip(KMZ) = zip ของ KML ให้มีขนาดเล็กลง
Global Administrative District Map(GADM) คือ การจัดการทำแผนที่เพื่อบ่งบอกเขตปกครองภายในเทศนั้นๆ โดยใช้ความละเอียดเชิงพื้นที่
สูงและชุดคุณลักษณะที่หลากหลาย
- ISO 3166-2 = ส่วนที่ 2 ของมาตรฐาน ISO 3166 อธิบายถึงตำแหน่งส่วนการปกครองต่างๆ ในแต่ละประเทศ หรือเขตการปกครอง
อิสระ จุดประสงค์ของการสร้างมาตรฐานเพื่อใช้เป็นคำย่อขนาดสั้น สำหรับสถานที่ ใช้ทั่วโลก ในปัจจุบันมีรหัสทั้ง 3700 รหัส
- Time Zone(TZ) = แผนที่แสดงเขตเวลาบนโลกที่แตกต่างกันแต่ละบริเวณ แต่ละเขตเวลามีความแน่นอนไม่เหมือนกัน
- Universal Time Co-ordinated (UTC) = หน่วยเวลาที่ใช้ในการอ้างอิงการหมุนของโลก โดยใช้เครื่องหมายบวก (+) หรือลบ (-) 
เทียบจากหน่วยเวลาสากลซึ่งเป็นระบบอ้างอิงจากเวลา GMT
- API code คือ คำสั่ง (Code) ที่อนุญาตให้ software program สามารถสื่อสารระหว่างกันได้
- bounding box คือกล่องสี่เหลี่ยมสำหรับปิดล้อมรอบบริเวณนั้นๆ หรือบริเวณที่ถูกกำหนดหมายเลข ซึ่ง
กล่องสี่เหลี่ยมนี้จะช่วยในการคำนวณจุดศูนย์กลาง พื้นที่ ความยาวแกนx-แกนy จุดพิกัด ฯ
ของบริเวณหรือวัตถุในภาพที่สนใจ

Map type แบ่งเป็น 3 แบบ
- Cylindrical Map Projections (ทรงกระบอก)
Mercator, Robinson, Goodes homolosine projection.
- Conic Map Projections  (ทรงกรวย)
- Azimuthal Map Projection  (ลูกโลก)
